What is Consensus?

🤝

Agreement Protocol

A consensus algorithm is a mechanism through which all participants (nodes) in a blockchain network agree on the current state of the distributed ledger — without needing a central authority.

🔒

Immutability

Once data is committed to the blockchain via consensus, it becomes practically impossible to alter. Each block is cryptographically linked to the previous, creating a tamper-proof chain of records.

👁️

Transparency

All transactions validated through consensus are visible to every participant in the network, ensuring complete transparency while maintaining the integrity of the system.

📈

Scalability

Different consensus algorithms offer different trade-offs in transaction throughput (TPS), block creation time, and network capacity — a key factor in blockchain design.

The Blockchain Trilemma

Every blockchain must balance three competing properties. No algorithm perfectly maximises all three — each makes trade-offs.

⚡

Scalability

The ability to handle a large number of transactions per second (TPS) with fast block creation times. High scalability means the network can grow without choking.

🛡️

Security

Resistance to attacks such as 51% attacks, Sybil attacks, and double-spending. A secure network ensures that no single entity can manipulate the ledger.

🌐

Decentralisation

The degree to which the network is distributed across independent nodes. Higher decentralisation means no single point of failure or control.

Layer Classification

Whether each blockchain operates at Layer 1 (the base chain) or Layer 2 (a scaling solution built on top of a base chain).

L1

Layer 1 — Base Chain

The foundational blockchain network that processes and finalises transactions on its own. It has its own consensus mechanism, native token, and independent security model. Examples: Bitcoin, Ethereum, Solana.

L2

Layer 2 — Scaling Solution

A secondary framework built on top of a Layer 1 chain to improve its scalability. L2 solutions process transactions off-chain and periodically settle on the base chain for security. Examples: Lightning Network (Bitcoin), Polygon, Arbitrum.
